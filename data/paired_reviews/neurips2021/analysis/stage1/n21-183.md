**Verdict.** Both committees recommended a poster, for the same reasons. Each saw a new formulation: personalized FL in which clients learn quantized models of different precision and architecture, joined by knowledge distillation, with a convergence proof. Each found the same gaps: full client participation only, no text experiments, full-precision training on devices, and a 1/√T rate. The main text promises a soft-quantizer derivation in Appendix A, but it is missing; the authors conceded this on both forums. Both forums got the same rebuttal: a sketched partial-participation proof, FEMNIST at 1/3 sampling, and AG News results. In A, three of four reviewers raised their scores. In B, one did, and the two 5s never replied. So A accepted on unanimous scores, and B on a 2-2 split that the chair broke. No rating exceeds 7, so neither committee considered more than a poster. No reviewer examined how thin the margins are. On FEMNIST, FedAvg + fine-tuning (96.72) ties 2-bit QuPeD (96.73), and Per-FedAvg is 0.15 below full-precision QuPeD.

**Committee A (poster).** Ratings 6, 6, 6, 7; confidences 4, 4, 3, 4. Reviewer_hK95 (5 hours) wrote the strongest critique, and the submission confirms each point. Algorithm 2 runs all n clients every round (line 2) and keeps state on each client. All baselines share one untuned learning rate (lines 369-370). FedAvg + fine-tuning is missing. It names the "straightforward combination" downside and omits every unresolved concern.
