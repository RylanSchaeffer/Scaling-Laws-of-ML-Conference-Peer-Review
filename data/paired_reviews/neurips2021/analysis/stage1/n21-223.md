**Verdict**

Both committees recommended a poster for the same reason. Both judged uncertainty estimates and a perturbation budget for LIME and KernelSHAP useful, and no reviewer found an error. The method's point estimate is LIME's or KernelSHAP's own (Remark 3.1). So its credible intervals measure only sampling uncertainty around the large-sample LIME or SHAP fit, and Table 1's "ground truth" is the same estimator at 10,000 perturbations (l.245-247). Both committees saw this fact. B's reviewers accepted it as a clarification. In A, Reviewer_TaGg gave 3. For TaGg, this fact and the ignored formal-explanation literature made the title's "Reliable" an overclaim. A's AC overrode that dissent. So the committees weighed the shared facts alike; A only had to set aside one principled detractor. B's acceptance leaned more on the rebuttal: before it, no B reviewer was above 6. Neither committee noticed that the user study reports standard errors of 0.003 with p = 0.028 for a 5-point gap (l.322-323). These numbers cannot both be right.
